# 🌐 Personal Portfolio Website

This is a responsive personal portfolio website designed and developed using **HTML, CSS, and JavaScript**. It serves as a digital profile to present my technical skills, academic background, and projects in a clear and organized manner.

The main goal of this project is to combine simple UI design, responsiveness, and modern web development practices to deliver a smooth user experience across all screen sizes.

---

## ✨ Highlights

- 📱 Responsive design optimized for desktop, tablet, and mobile devices  
- 🎨 Clean and minimal user interface with a modern look  
- 🧭 Smooth navigation between sections  
- 🧑‍💻 Structured sections for About Me, Skills, Services, Projects, and Contact  
- 🔗 Direct links to GitHub, LinkedIn, and other social platforms  
- 📩 Contact form for easy and quick communication  
- 🚀 Deployed and hosted using GitHub Pages  

---

## 🛠️ Tech Stack

- **HTML5** – Page structure and semantic elements  
- **CSS3** – Layout design, animations, and responsiveness  
- **JavaScript** – Interactive features and DOM manipulation  
- **Typed.js** – Dynamic typing effect  
- **Boxicons & Font Awesome** – Icons and UI enhancements  
- **GitHub Pages** – Project hosting and deployment
